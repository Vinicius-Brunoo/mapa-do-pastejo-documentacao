02 · Banco de dados

Quatro tabelas de negócio

A tabela usuarios serve ao login e não entra na contagem. Todas possuem o campo removido para a exclusão lógica.

pasto

  • PK pastoid
  • descricao
  • areatotal
  • removido

piquete

  • PK piqueteid
  • descricao
  • latitude / longitude
  • FK pastoidfk
  • removido

animal

  • PK animalid
  • nome
  • datanasc
  • removido

alocado

  • PK alocadoid
  • FK animalidifk
  • FK piqueteidfk
  • datainicio / datafinal
  • removido
Relacionamentos: um pasto possui vários piquetes; animais e piquetes se relacionam por meio do histórico de alocações.

Exclusão lógica

O DELETE executa um UPDATE: removido = true. Os dados continuam no banco, mas deixam de aparecer nas consultas.

Tipos pedidos

VARCHAR para textos, NUMERIC para área e coordenadas, e DATE para datas.

Login acadêmico

A base inicial cria admin / admin. A senha simples foi mantida apenas para a demonstração acadêmica.

Login

POST /Login consulta o usuário. Se a senha estiver correta, o back-end cria um JWT válido por dez minutos.

JWT

O front envia Authorization: Bearer TOKEN. Sem token válido, o controller do CRUD não é executado.

Código simples

O controller só lê os dados, chama o model e responde. O projeto não adiciona tratamento global de erros.

routerApp.put("/updatePasto/:pastoid",
  appLogin.AutenticaJWT,
  appPastos.UpdatePasto
);

04 · Front-end

Uma função para cada API

O servidor do front roda na porta 40103. As views Nunjucks montam as páginas e os arquivos JavaScript usam fetch para conversar com a API.

Login: o usuário informa nome e senha; o navegador chama POST /Login.
Armazenamento: após o login, o JWT é salvo no localStorage.
Listagem: a tela chama uma rota getAll... e monta a tabela.
Formulário: os modos inserir, editar e excluir chamam POST, PUT e DELETE.
Relacionamentos: piquete carrega pastos; alocação carrega animais e piquetes para os campos de seleção.

05 · Execução

Três serviços no Docker

O Compose inicia PostgreSQL, back-end e front-end. O banco recebe o SQL inicial somente quando o volume é criado.

1

banco

PostgreSQL 16, banco dw3_pastejo e volume pastejo_dados.

2

backend

Node + Express na porta 40003. Aguarda o healthcheck do PostgreSQL.

3

frontend

Express + Nunjucks na porta 40103. O navegador acessa a API pela porta 40003.

# primeira execução
cp .env.example .env
docker compose up --build -d

# abrir no navegador
http://localhost:40103

# parar sem apagar os dados
docker compose down
