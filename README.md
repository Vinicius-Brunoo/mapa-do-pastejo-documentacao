# Guia do Pastejo Rotacionado

Repositório de documentação do projeto acadêmico **DW3 — Pastejo Rotacionado**.

- [Abrir o guia visual](https://vinicius-brunoo.github.io/mapa-do-pastejo-documentacao/)
- [Abrir o código do sistema](https://github.com/Vinicius-Brunoo/dw3-trabalho3-pastejo)
- [Material usado como referência](https://github.com/ArielAio/mapa-do-pastejo)

## O que este guia explica

- arquitetura cliente-servidor;
- divisão entre front-end, API e PostgreSQL;
- organização MVC;
- tabelas e relacionamentos;
- login e proteção das rotas com JWT;
- vinte APIs de CRUD;
- exclusão lógica com o campo `removido`;
- execução dos três serviços com Docker Compose;
- roteiro curto para apresentação do trabalho.

## Como abrir localmente

O guia não possui dependências. Basta abrir o arquivo `index.html` no navegador.
